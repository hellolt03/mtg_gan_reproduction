## 已证实的主要问题

证据来自旧源检查点与训练分区，不读目标标签、不更新权重：[structural_audit.json](../runs/bgl_to_thunderbird_pilot_20261026/structural_audit.json)。脚本为 `scripts/audit_transfer_structure.py`。

1. **源域没有训练目标的新输出槽位。** 源/目标词表 172/1,192，目标多出的 1,020 个槽位占 85.57%；对应解码器权重、偏置、掩码输出行在源训练后仍与预训练检查点完全一致。抽查三个目标训练图，新目的节点预测连边概率均约 0.501，而真实边密度约 0.000002–0.001462，输出明显过密。
2. **编号敏感且没有共享语义坐标。** 对同一个图同时重排特征和邻接，生成器相对置换误差在抽查中约 0.97–1.41，判别器也改变输出。固定语义槽位的 FFN 本可依赖已知次序，但当前各域独立频率排序没有提供这种对应，所以成为跨域缺陷。
3. **字节片段破坏时间连续性。** BGL/Thunderbird 训练图间最大空档约 129.61/294.91 小时，超过各自窗口长度的空档有 25/40 处。当前上下文没有片段边界约束，TCN 会跨空档连接图。
4. **规模和损失存在异常。** 判别器 94,638,273 参数，生成器 315,520 参数；巨型 FFN 的多数位置在源域没有真实信号。旧测试全局分数中位数源约 2.49、目标迁移前约 19,634.31；目标谱损失近乎不变、梯度惩罚上升。谱热核饱和是待检验机制，不先认定为唯一原因。

补充单图探针：源模型对第一个目标训练样本的谱损失约 1190.0284，对预测邻接的梯度范数仅 `1.45e-8`，预测热核距均匀投影的 Frobenius 距离约 `2.67e-4`。这确认该样本的原始热核近乎饱和，谱项对连边学习信号很弱；不能由一个样本推断所有轮次都如此。

共享解码器可采用 `p(i,j)=sigmoid((Wq h_i)^T(Wk h_j)/sqrt(d))`，使不同目的节点使用同一组参数，保留有向关系。学习型掩码必须一起消除编号参数，否则只修改解码器仍然编号敏感。判别器使用图读出而不是手工编号矩阵的位置。

当前重建实现和检查点保留为 `legacy` 诊断基线。上述模型结构变动属于**归纳式扩展版本**，不能直接称为作者的严格原实现。若坚持原文 FFN 结构，则需要另外建立可靠的共享语义槽位，例如源训练模板构造的语义锚点，再将目标映射进去；这是需要检验的对齐假设，不能用各域频率排序代替。

## 数据与评分的具体约束

正式实验优先处理三份现有文件的完整范围。若资源要求先做小规模验证，使用完整连续时间段，或为多个连续片段保存 segment ID 并禁止跨片段构造 TCN 历史；不能继续将离散字节片段当作连续日志。没有真实日志的空窗与人工抽样缺口必须区分。

三域各保留固定训练/验证/测试 ID；Drain 匹配规则和训练统计冻结。归纳式候选可为未匹配模板保留规范化文本及冻结语义表示，避免全部折叠进同一 UNKNOWN，但不得据测试数据更新训练统计或使用测试标签。

局部索引仅用于图计算，不承担跨域语义对应；图读出按实际出现节点统计，不把整个域词表当作每张图的全部事件。预测候选范围须明确来自历史或训练词表；当前目标图的边和标签不能用于生成器输入。新出现节点如何评分需单独定义，不能通过掩掉它们来消除异常分数。

原全局分数是对称 delta L 的特征值 L2 范数，数学上等于 delta L 的 Frobenius 范数，会受规模影响。归一化 Laplacian 和按实际节点数归一化属于待比较方案；局部、全局分项只在允许的训练/验证数据上估计尺度。**正的单调线性缩放不能提高已有 AUC**，因此调整分数尺度只能解决一部分阈值问题，不能替代表示和排序改进。

优先做源域正常验证校准，目标训练无标签校准作为单独协议报告。先固定阈值验证，再比较动态阈值，记录后者实际激活次数。目标测试标签只作最终评估，不选择轮数、混合权重或分位数。

## 执行顺序和验收

1. 三域一次性数据审计、连续分段与共享缓存，记录有效样本数、类别统计和分区 UNKNOWN 比例。不得根据测试指标挑选更好看的时间段。
2. 对候选模型做节点重排、padding、不同节点数和新节点前向检查；eval 下的置换误差应在数值误差范围内。对原 FFN 分支应验证共享语义槽位的一致性，而不是强行要求任意重排不变。
3. 分别建立三域源模型，先比较“上一图直接作为下一图”的持久性基线，检查源域召回、PR-AUC、预测密度、正负边误差及各损失梯度。训练轮数和改动使用源域允许的验证信息确定，记录源标签用途。
4. 一个固定种子跑完六个迁移方向；每方向报告 source、迁移前 target、适配后 target。只改一个可独立检验的因素；共享掩码/解码器/判别器可作为满足归纳条件的整体改动，不把整体收益归给单模块。
5. 方法与协议固定后跑 42/43/44 三个种子：至少 18 次迁移实例，报告方向均值/标准差和六方向宏平均，保留全部失败结果。新主线确认使用独立测试，不把已多次诊断的 pilot 当最终证据。

每个种子只训练 BGL、Spirit、Thunderbird 三个源模型，再分别复制给两个目标，禁止适配第一个目标后的权重继续适配第二个。新版 `preparation_digest` 已拆分：源阶段仅依赖源准备产物，目标阶段依赖两域；源训练签名与种子也需匹配。旧分支保持历史兼容。

已采用结构：`prepared/inductive_v2/{domain}/{fingerprint}/` 共享数据；`source_runs/inductive_v2/{source}/seed{seed}/` 源检查点；`runs/inductive_v2/{source}_to_{target}/seed{seed}/` 独立适配。上述目录待运行后生成。汇总已支持混淆计数、阳性率、AP、ROC-AUC、F1 与多种子均值/标准差；AP 为 average precision，不将其混称为梯形积分 PR-AUC。完整节点覆盖与峰值资源报告仍须补充。

## 原理参考与方法边界

[GraphSAGE](https://arxiv.org/abs/1706.02216) 提供通过节点特征和共享邻域函数推广到未见节点/图的研究依据；[Deep Sets](https://arxiv.org/abs/1703.06114) 给出置换不变/等变函数的结构依据；[WGAN-GP](https://arxiv.org/abs/1704.00028) 是梯度惩罚机制的来源。它们支持候选设计的原则，不证明能在当前日志任务取得提升，也不能替代 MTG-GAN 作者实现的核对。
